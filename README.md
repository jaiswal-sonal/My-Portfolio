# Sonal Jaiswal – Portfolio

Personal portfolio website built with React + TypeScript.

## 🚀 Deploy in 3 Steps (Free via Vercel)

### Step 1 – Push to GitHub
```bash
cd sonal-portfolio
git init
git add .
git commit -m "Initial portfolio commit"
git remote add origin https://github.com/YOUR_USERNAME/portfolio.git
git push -u origin main
```

### Step 2 – Deploy on Vercel (FREE)
1. Go to [vercel.com](https://vercel.com) → Sign in with GitHub
2. Click **"Add New Project"**
3. Import your `portfolio` repository
4. Leave all settings as default → Click **Deploy**
5. ✅ Your live URL will be: `https://sonal-portfolio.vercel.app`

### Step 3 – Update your GitHub username in the code
Search and replace `SonalJaiswal` with your actual GitHub username in:
- `src/components/Hero/Hero.tsx`
- `src/components/Project/Project.tsx`
- `src/components/Footer/Footer.tsx`

Also update the LinkedIn URL in `src/components/Hero/Hero.tsx`.

## 📌 Things to Personalize
- Add your actual profile photo: replace the placeholder in `About.tsx`
- Update LinkedIn profile URL in `Hero.tsx`
- Add your resume PDF to `src/assets/` and link it in `Header.tsx`
- Update GitHub repo links per project in `Project.tsx` if repo names differ

## 🛠 Local Development
```bash
npm install
npm start
```
