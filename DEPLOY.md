# 🚀 How to Deploy Your Portfolio

## Step 1 — Push to your GitHub repo

Open terminal in this folder and run:

```bash
git init
git add .
git commit -m "Add personalized portfolio with photo and resume"
git branch -M main
git remote add origin https://github.com/jaiswal-sonal/my-portfolio.git
git push -u origin main
```

> If the remote already exists: `git remote set-url origin https://github.com/jaiswal-sonal/my-portfolio.git`

---

## Step 2 — Deploy FREE on Vercel (get live link in 2 mins)

1. Go to 👉 [https://vercel.com](https://vercel.com)
2. Click **"Sign in with GitHub"**
3. Click **"Add New Project"**
4. Select your `my-portfolio` repository
5. Leave all settings as default
6. Click **"Deploy"** ✅

Your live URL: `https://my-portfolio-jaiswal-sonal.vercel.app`
